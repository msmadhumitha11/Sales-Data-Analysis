# Sales Data Analysis

## 📌 Project Overview

This project analyzes sales data using Python to understand sales performance, quantity sold, and profit.

## 🎯 Objectives

- Calculate total sales
- Calculate total quantity sold
- Calculate total profit
- Analyze sales data
- Generate useful business insights

## 🛠️ Tools & Technologies

- Python
- Pandas
- NumPy
- Matplotlib

## 📂 Dataset

The dataset contains sales-related information such as:

- Sales
- Quantity
- Profit
- Product details

## 🔍 Analysis Performed

The project includes:

- Data loading
- Data exploration
- Sales calculations
- Quantity analysis
- Profit analysis
- Data visualization

## 📊 Key Insights

The analysis helps understand:

- Overall sales performance
- Products and categories contributing to sales
- Quantity sold
- Profit generated

## ▶️ How to Run

1. Download or clone this repository.
2. Install the required Python libraries.
3. Run `Sales_analysis.py`.
